## Uncertainty-informed diagnosis

Uncertainty-informed diagnosis of diabetic retinopathy (DR) uses deep neural networks.

Using the categories from CSS581 Homework 1, Question 3, this is a **classification** task because the model predicts a discrete diagnostic category. Its outputs are confidence scores for the categories. Producing numerical confidence scores does not make the task regression: the prediction target is a category rather than a continuous quantity.

### Miscalibration of probabilistic outputs

The problem is **miscalibration of probabilistic outputs**. A classifier's probabilistic outputs should reflect the true probability that its predictions are correct. A classifier with this property is **well-calibrated**.
