## NN classification cont.

**Nearest neighbors expose the hidden choices in ML.**

- **Almost no training:** Store the labeled examples; most of the work happens at prediction time.
- **Geometry is the model:** The representation and distance function determine which examples count as similar.
- **$k$ controls complexity:** A single integer moves the classifier from highly local decisions toward a global majority.
- **Evaluation matters immediately:** Training error can look perfect while test behavior is poor.

## Input representation

A raw object must become something we can compare.

For MNIST, a $28 \times 28$ grayscale image can be flattened into a vector $x \in \mathbb{R}^{784}$.

## Local smoothness assumption

The **local smoothness assumption** is that if a query point is close to other points, they should have the same labels. In k-NN, local similarity carries label information, with closeness measured by the distance function $d(x,z)$.

With unweighted Euclidean distance, **every coordinate starts out equally important**.

## Choosing a distance function

Euclidean distance does not work well in every situation. Different advanced distance functions can be used depending on the problem. **Euclidean distance is a geometric choice.**

Two images of the same digit can have a high Euclidean ($\ell_2$) distance. Better distance measures can be invariant under transformations:

- *Tangent distance* handles small translations and rotations.
- *Shape context* handles a broader family of natural deformations.

| Distance measure | Test error rate |
| --- | --- |
| $\ell_2$ | 3.09 |
| Tangent distance | 1.10 |
| Shape context | 0.63 |

More generally, **better representations can improve nearest-neighbor classification**.

## Cross-validation

### Choosing K

K-nearest neighbor classification assigns a point a label using the labels of its $K$ nearest neighbors among the training points.

The MNIST results show that **a larger $K$ does not necessarily improve performance**.

The practical question is how to choose the best $K$ when no test set is available.

**Cross-validation** estimates the error of k-NN for a particular $k$.

### 10-fold cross-validation

1. Divide the training set $S$, containing 60,000 points, into 10 equal pieces: $S_1, S_2, \ldots, S_{10}$. Each piece contains 6,000 points.
2. For each piece $S_i$, classify every point in $S_i$ using k-NN with training set $S - S_i$. Let $\epsilon_i$ be the fraction of points in $S_i$ that are incorrectly classified.
3. Average the 10 error values to obtain the estimated error for that $k$:

$$
\text{estimated error with k-NN}
= \frac{\epsilon_1 + \cdots + \epsilon_{10}}{10}.
$$

### Batching versus cross-validation

Cross-validation estimates error using held-out portions of the training data. Batching concerns learning from pieces of the training data rather than testing. For MNIST, the model learns from one piece of the training data and then moves on to the next.

Batching will be discussed more thoroughly later in the course.

## Speeding up nearest neighbor search

Naive nearest neighbor search takes **$O(n)$ time** for a training set of size $n$, which is too slow.

Data structures for speeding up nearest neighbor search include:

- Locality sensitive hashing.
- Ball trees.
- K-d trees.

### K-d trees

A **K-d tree** splits the space into regions with the same amount of data in each region. It forms a hierarchical, rectilinear spatial partition.

For a dataset $S \subset \mathbb{R}^d$:

1. Pick a coordinate $1 \leq i \leq d$.
2. Compute the median along that coordinate:

   $$
   v = \operatorname{median}(\{x_i : x \in S\}).
   $$

3. Split $S$ into two halves:

   $$
   S_L = \{x \in S : x_i < v\}, \qquad
   S_R = \{x \in S : x_i \geq v\}.
   $$

4. Recurse on $S_L$ and $S_R$.

Given a query $q \in \mathbb{R}^d$, there are two search methods:

| Search method | Procedure |
| --- | --- |
| **Defeatist search** | Route $q$ to a leaf cell and return the nearest neighbor in that cell. This might not be the true nearest neighbor. |
| **Comprehensive search** | Expand the search region to other cells that cannot be ruled out using the triangle inequality. |

## Distance functions for ML

**Similar things should be nearby.** Distance represents an idea of similarity, even when the function does not explicitly state that idea.

### Measuring distance in $\mathbb{R}^m$

The usual choice is **Euclidean distance**:

$$
\|x-z\|_2 = \sqrt{\sum_{i=1}^{m}(x_i-z_i)^2}.
$$

For $p \geq 1$, the **$\ell_p$ distance** is:

$$
\|x-z\|_p = \left(\sum_{i=1}^{m}|x_i-z_i|^p\right)^{1/p}.
$$

Here, $m$ is the number of dimensions (coordinates) in each vector. The parameter $p$ determines which $\ell_p$ distance is used: it is the exponent applied to each absolute coordinate difference, followed by taking the $p \text{th}$ root of the sum.

The roles of $m$ and $p$ are different: **$m$ describes the data's dimensions; $p$ controls how distance is measured.** Changing $p$ does not change the vectors or their number of dimensions.

- As $p$ decreases toward 1, smaller coordinate differences contribute more relative to the largest difference. Several moderate differences can add up to a large distance.
- As $p$ increases, the largest coordinate difference increasingly dominates. At $p=\infty$, only the largest absolute coordinate difference determines the distance.

Changing $p$ can change which points count as nearest neighbors and therefore change a k-NN prediction.

**Ordinary Euclidean vector length uses $p=2$, regardless of $m$:**

$$
\lVert x\rVert_2 = \sqrt{x_1^2+x_2^2+\cdots+x_m^2}.
$$

Other values of $p$ define other ways to measure length.

The important special cases are:

| Choice | Distance |
| --- | --- |
| $p=2$ | Euclidean distance: $\lVert x-z\rVert_2 = \sqrt{\sum_{i=1}^{m}(x_i-z_i)^2}$ |
| $p=1$ | $\ell_1$ distance: $\lVert x-z\rVert_1 = \sum_{i=1}^{m}\lvert x_i-z_i\rvert$ |
| $p=\infty$ | $\ell_\infty$ distance: $\lVert x-z\rVert_\infty = \max_i \lvert x_i-z_i\rvert$ |

> ***Memorize this distance formula. In particular, $\ell_\infty$ distance is the maximum absolute coordinate difference.***

As $p$ approaches infinity, the largest absolute coordinate difference dominates when each difference is raised to the power $p$. Taking the root of order $p$ makes the distance approach that maximum:

$$
\lim_{p\to\infty}\left(\sum_{i=1}^{m}\lvert x_i-z_i\rvert^p\right)^{1/p}
= \max_i \lvert x_i-z_i\rvert.
$$

### Metric spaces

Let $\mathcal{X}$ be the space in which the data lie. A distance function $d : \mathcal{X} \times \mathcal{X} \to \mathbb{R}$ is a **metric** if it satisfies all four properties:

- **Nonnegativity:** $d(x,y) \geq 0$.
- $d(x,y)=0$ if and only if $x=y$.
- **Symmetry:** $d(x,y)=d(y,x)$.
- **Triangle inequality:** $d(x,z) \leq d(x,y)+d(y,z)$.

### A non-metric distance function

Let $p$ and $q$ be probability distributions on a set $\mathcal{X}$. The **Kullback-Leibler divergence**, also called **relative entropy**, between $p$ and $q$ is:

$$
d(p,q) = \sum_{x\in\mathcal{X}} p(x)\log\frac{p(x)}{q(x)}.
$$

For a coin toss, compare two probability distributions:

| Outcome | Fair coin $p$ | Biased coin $q$ |
| --- | --- | --- |
| Head | 50% | 70% |
| Tail | 50% | 30% |

To measure how different these two coins are, compute:

$$
d(p\|q)
= 0.5\log\left(\frac{0.5}{0.7}\right)
+ 0.5\log\left(\frac{0.5}{0.3}\right).
$$

- The divergence is positive for these two different distributions
- $d(p\|p)=0$. 
- However, **KL divergence is not symmetric**: $d(p\|q) \neq d(q\|p)$ in this example. 

Therefore, this is not a metric distance function.

## Image classification with weights and softmax

The task is to take an image and decide whether it is a dog, cat, or car. Represent the image as a vector $\underline{x} \in \mathbb{R}^d$ and compute a score using a weight vector for each class:

| Class | Score | Exponentiated score |
| --- | --- | --- |
| Dog | $\underline{w}_d^T\underline{x}=2$ | $e^2$ |
| Cat | $\underline{w}_{ct}^T\underline{x}=7$ | $e^7$ |
| Car | $\underline{w}_{car}^T\underline{x}=-1$ | $e^{-1}$ |

**Softmax** converts the scores into class probabilities by exponentiating each score and dividing by the sum of the exponentiated scores. For the dog class:

$$
P(\text{dog}) = \frac{e^2}{e^2+e^7+e^{-1}}.
$$

### Comparing the correct label with the prediction

For an image whose correct label is car, use the class order dog, cat, car. The correct label is represented by the **one-hot distribution** $[0,0,1]$: all probability is assigned to car.

The model's softmax output is $(p_1,p_2,p_3)$, where $p_1$ is its predicted probability of dog, $p_2$ of cat, and $p_3$ of car. These probabilities sum to 1. Here, the subscripts identify classes; this notation is separate from the parameter $p$ in $\ell_p$ distance.

**KL divergence compares the correct class distribution with the predicted class distribution.** It measures their mismatch, rather than comparing the image's pixel vector with a car image.

$$
\begin{aligned}
\operatorname{KL}([0,0,1]\,\|\,(p_1,p_2,p_3))
&= 0\log\frac{0}{p_1}+0\log\frac{0}{p_2}+1\log\frac{1}{p_3} \\
&= -\log p_3.
\end{aligned}
$$

The terms with zero target probability contribute zero, using the convention $0\log(0/q)=0$ for $q>0$.

For this one-hot target, the result is also the **cross-entropy loss**. A predicted car probability $p_3$ close to 1 gives a loss close to zero; a small $p_3$ gives a large loss. The model is penalized for assigning low probability to the correct class.
